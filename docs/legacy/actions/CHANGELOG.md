# 更新记录

## 1.1.0 — GD656 探头移植与 GWO 适配

- 移除旧探头实现和旧动画资源，移植 GD656 原姿态、角度、时长、双轨插值与回正曲线。
- 不执行原模组的实体横移和整模型偏移，保留人物坐标、碰撞箱及腿部姿态。
- 相机和虚拟射击眼位代替原实体横移；碰到墙体时仅限制视点偏移，不改探头动画。
- 接入 GWO 独立第一人称渲染、原生第三人称持枪手臂和原生服务端开火眼位。
- 增加探头网络同步、自动掩体探头及可选按键切换模式，保留已有蹲、跳、疾跑、趴下规则。
- 保留 Minecraft_GD656 署名和 MIT 条款，不打包 GD656/GWO JAR 或受保护枪械资源。

验证：22 项单元测试；实际 GWO 客户端/集成服务器 4,245 项断言、1,910 帧，通过原始动画前四刻对照、实体坐标/碰撞箱、独立渲染、原生第三人称姿态以及服务端子弹起点检查。不安装 GWO 的独立客户端通过 2,683 项断言、1,091 帧。使用测试枪配置，未验证具体受保护枪包画面。

## 1.0.3 — 战术动作输入冲突修复

- 保持 Q 左探头、E 右探头及现有蹲、跳、疾跑、Z 趴下绑定。
- 左右探头共用一个平滑倾斜值；双键同时按住时回正，松开其中一键后恢复仍按住的方向。取消反复堆叠的探头动画过渡层。
- 上半身围绕髋部倾斜，双腿不参与；保留头部上下观察和手臂原有动作。身体和第一人称侧移方向一致，贴墙时限制侧移。
- 跳跃、腾空会锁定主动蹲伏，落地后保持站立。必须在地面松开再按蹲键，才允许再次蹲下；不缓存空中的蹲伏请求。
- 蹲下起跳先站立一个游戏刻，再执行跳跃。头顶空间不足时保留原版被动压低身体，不强制穿过方块。
- 蹲伏阻止疾跑重新启动，修复持续按住疾跑抢占蹲伏的情况；松开蹲伏后允许仍按住的疾跑恢复。
- 保留原版游泳、飞行、骑乘、攀爬和自定义趴下的专用输入处理。

验证：12 项单元测试通过；独立 NeoForge 1.21.1 / PAL / GWO 客户端执行 19 项输入与物理状态断言，通过 28 阶段动作截图序列，并检查左右探头、双键回正、第一人称和趴下侧面截图。

验收产物：`build/reports/1.0.3/`。测试代码位于 `src/visualTest`，不包含在发布 JAR 中。

范围：以上验证针对本地玩家。没有新增其他玩家的战术动画网络同步，也未修改服务器弹道或实体受击盒。
