# 口袋轮盘

适用版本：Drag Inventory 2.3.1 / Minecraft 1.21.1 / NeoForge 21.1.251 / LDLib2 2.2.40。

## 操作

- 持续按住左 Alt 或右 Alt 约 50 毫秒打开，按住期间保持菜单；小于 50 毫秒的短按不触发。
- 松开 Alt 确认当前高亮物品，立即同步服务端并关闭；中心 15 屏幕像素死区保留当前候选，无候选时只关闭。
- 按住期间移动鼠标指向扇区，左键按鼠标方向选取扇区装备对应栏位并关闭，立即同步服务端。
- 右键或 Esc 关闭，不切换快捷栏；失焦、死亡、退出世界和被其他界面替换也会取消。
- 鼠标在屏幕任意位置都按相对中心的方向选择；移出轮盘不取消。距离中心小于 15 个实际屏幕像素时保持当前候选，已有候选可左键或松开 Alt 确认。
- 滚轮向上选择上一格，向下选择下一格，与快捷栏方向一致。高亮候选变化，左键点击扇区或松开 Alt 才装备。
- 滚轮后鼠标静止会保留候选，实际移动鼠标后恢复指向选择。

五个扇区对应原物理第 5–9 格。刚打开时，从顶部顺时针是 5、6、7、8、9；滚动后部件位置随自旋变化，图标和栏位标号仍对应各自实际物品。

显示原版物品图标、完整数量、耐久/冷却装饰、当前装备的白色轮廓和候选的薄荷绿色高亮。空格保留位置，可以选为空手。当前装备与候选在确认前分别显示。死区大小不随 GUI 缩放或入场缩放改变；自旋后的指向与可见扇区对应。

顶部标题固定为“口袋”两个字，中英文语言设置都保持这个标题。轮盘下方没有操作说明或取消提示。长物品名称在中心自动分行/截断；5–9 的键帽读取玩家实际绑定。

## 动画与输入

入场只淡入和缩放，持续 180 毫秒；没有入场旋转。滚动时每格产生 72° 的整轮自旋，180 毫秒贝塞尔过渡。连续滚动积累目标并从当前姿态重新过渡，反向滚动也保持连续。

高亮切换持续 150 毫秒，伴随轻微外移、图标放大和选择脉冲。关闭时冻结当前角度，150 毫秒独立淡出；鼠标视角立即恢复。关闭点击保留为菜单操作，避免穿透到攻击或使用物品。

在“按键绑定 → Drag Inventory”修改“长按打开口袋轮盘”，支持键盘改绑及修饰键。游戏继续运行，轮盘界面负责当前鼠标/键盘输入；正常 HUD 在轮盘及淡出期间暂时隐藏，结束后恢复。

## 构建与验证

```powershell
.\gradlew.bat clean build
.\gradlew.bat runClient -PwheelSmoke
```

第二个命令只使用独立 `run-wheel-smoke` 实例和新建的自动测试存档。它通过真实 NeoForge 输入事件在同一客户端 tick 内模拟 Alt 按下/释放，验证短按不触发；通过游戏鼠标回调定位，执行生产 Screen 的左键、右键与滚轮处理。

测试检查五格选择的实际原版同步包和集成服务器栏位、松 Alt 确认并关闭、滚轮循环和静止指针保持、自旋中间帧、取消、鼠标恢复、视角保持、图标数量/空格及 GUI 缩放 2/3。生成六张截图和逐帧动画 CSV 后自动退出，日志成功标记 `WHEEL_SMOKE_PASS`。测试代码只在 `-PwheelSmoke` 时进入运行环境，发布 JAR 不含 `WheelSmoke`。

核心代码：`src/main/java/dev/draginventory/client/wheel/`；提交复用 `WeaponScroll.select()` 与原版持有物品栏位同步，其他背包/HUD/体力/地图功能沿用现有项目。
