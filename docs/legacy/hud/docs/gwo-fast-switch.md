# GWO 快速切枪

Drag Inventory 2.3.1，Minecraft 1.21.1 / NeoForge 21.1.251；已验证 GWO-Beta1.0-Fix-0.5（内部版本 2.12.87）。

## 默认效果

收枪和拔枪默认 2 倍速。当前枪包 M4 的原始收枪 700ms、普通拔枪 800ms，动作时长缩短到 350ms 和 400ms；实际就绪还包含原生 20Hz 更新和首帧调度。测试枪完整切换约 851ms。

模型动画播放速度、动画过渡、GWO 的握枪姿态计时以及 `raise` / `drop` 动作任务统一缩短。裁切了 `clip_start/end` 的切枪片段按实际可见窗口结算，避免画面已经结束却还等待完整片长。数字键、滚轮和口袋提交均立即同步当前持有栏位。

切枪状态与动作任务按原生完成流程结束，随后由 GWO 的正常输入缓冲和开火发包流程恢复射击；保留弹药、射速、换弹、上膛、卡壳、冲刺姿态及首次特殊动作的原有规则。

## 调整速度

启动一次客户端后，编辑游戏实例中的 `config/draginventory-switch-client.toml`：

```toml
switchSpeed = 2.0
```

`1.0` 恢复原速，`2.0` 是默认双倍速；范围 1.0–6.0。需要更快可尝试 2.5 或 3.0。调整完成后重启游戏。

此配置仅调节 GWO 切枪的客户端动画及对应就绪时间。没有安装 GWO 时兼容代码跳过，不影响普通 Minecraft 或口袋轮盘。

## 实现与验证

动作规划期间使用短同步作用域区分 `raise` / `drop` 与其他动作，保证自定义切枪片段可加速，换弹即使复用同名片段也保留原计时。作用域在异常时也会清理。播放侧按原生任务 owner 筛选，其他手部动作不会统一加速。

复现：

```powershell
.\gradlew.bat clean build
.\gradlew.bat runClient -PswitchSmoke
```

在独立 `run-switch-smoke` 实例放入自己的 GWO JAR。测试通过公开原生 API 注册纯配置测试枪，使用真实集成服务器玩家，走原生切枪状态机、时间轴、左键输入、FirePayload、弹药消耗与 BulletEntity 创建。测试枪不依赖受保护枪模资源，因此验证的是实际播放时钟和机制链，不宣称实测了受保护模型的画面。

验证包含 2 倍时间轴、裁切窗口、原生动作锁与握枪进度同步、快速连续切换保留最后枪、真实开火扣弹、换弹仍阻挡开火、原版 74ms 射击间隔。结果标记 `GWO_FAST_SWITCH_SMOKE_PASS`，采样在 `switch-smoke/frames.csv`。

口袋菜单的全屏方向选择、15 像素死区、Alt 松开确认、左键选取、右键取消和滚轮自旋继续保留。
