# Drag Inventory — 拖动物品栏与 LDLib2 快捷栏

战术地图：按 `M` 打开大地图（默认完整界面，可在设置视觉页开启“打开时进入清屏模式”只显示地图、玩家与标点，`H` 随时切换）；底图彩色——按真实方块颜色实时采样成图（Xaero 风格），六种滤镜预设（三角洲/塔科夫/暗区突围/Apex/PUBG/关闭，v2.5.3 重做向原游戏风格对齐）可切换，默认彩色无滤镜，缩放范围 108%~600%（v2.5.5）；玩家位置图标为 SVG 原图纹理化导航箭头（v2.5.9：严格遵循用户提供的 玩家位置图标.svg 原图——纯 #32CD32 平面单色，无明暗差、无折痕、无软影，原图离线栅格化为 256×256 抗锯齿纹理，走原版 GuiGraphics.blit + SimpleTexture 纹理管线 + .mcmeta 线性过滤，任意缩放边缘平滑如矢量，视觉大小与 v2.5.7 一致，v2.6.0 起大小可调——设置 GUI 标点页滑条或 /map player_size 调整（40%~100%，默认 100%，作用于小地图/大地图/设置预览与尾迹）；移动时平滑转向、沿运动方向弹性拉伸、身后渐隐尾迹，静止轻微呼吸）；楼层恒定自动跟随玩家所在层。左上角常驻方形小地图（默认 96 像素，菜单可开关、缩放与尺寸可调）与大地图显示同一层，下方居中只显示倒计时数字本体（v2.6.0：只留 m:ss 加粗数字，无前后缀文案；进入世界自动开始，醒目金色、最后 60 秒转红闪烁、秒位跳变脉冲与冒号呼吸动效全保留，归零字样停留约 2.5 秒后消失（v2.6.1），/map timer 手动对表）；地图右键可放地点/敌情/物资三种标点（数字键 1/2/3 切换并弹出底部反馈，`C` 清除）；图例与标点管理弹窗从画布左侧伸出；完整界面与清屏模式的右下角均显示全套快捷键说明。全部快捷键均为主键盘核心键区（M/H/C/1/2/3/空格），不依赖小键盘与 PageUp/Home 等扩展键，键位可在原版按键绑定（Drag Inventory 分类）中修改。`/map` 全套子命令与五页签设置 GUI 可调全部参数。操作和开发验证见 [战术地图说明](docs/factory-tactical-map.md)，使用手册见 [战术地图 Wiki](wiki/战术地图.md)，联动接口（标点/对局倒计时/POI，v2.5.7 起供对局系统接入）见 [战术地图 API](wiki/战术地图API.md)。

适用：Minecraft Java 1.21.1 + NeoForge 21.1.251，Java 21。
版本：2.6.1。界面和拖拽功能在客户端运行，玩家基础最大生命值 100 和体力消耗、恢复在服务端计算。体力通过 NeoForge 数据附件同步给玩家自己的客户端，不添加物品。1.5.0 起内置方位条 HUD（顶部罗盘，五套游戏风格皮肤，使用手册见 `wiki/方位条HUD.md`）。

2.6.1 方位条默认预设重调 + 倒计时归零字样停留后消失：
方位条出厂预设按用户实测反馈重调（用户反馈默认观感不佳）：默认皮肤 delta → apex（悬浮式、两端 Alpha 渐隐、视觉最轻）；顶部对齐 offset_y 6 → 0（与快捷对齐"贴顶"同值）；条宽 240 → 427（640 GUI 宽下 2/3 屏宽预设值）；老玩家升级后首次加载一次性收敛（标记驱动，仅动仍是旧默认值的项，玩家自定值一律保留，此后改回旧值被永久尊重）。对局倒计时归零后的红色"对局已结束"字样停留约 2.5 秒后整行消失（用户给定 2~3 秒区间取中值；不再常驻，重新开始计时会重新出现，`/map timer off` 隐藏不是结束）。新增配置标记 `general.defaults_retuned`；全套 181 用例全绿。

2.6.0 玩家图标大小可调 + 倒计时只留数字：
新增玩家位置图标大小自定义（设置 GUI 标点页"玩家图标大小"滑条，或 `/map player_size <0.4~1.0>`，反馈按百分比显示）——1.0 = 默认尺寸（上限，形状高 ≈12.5px），最小 40%（≈5px，小地图上仍清晰可辨）；作用于小地图/大地图/设置预览与尾迹残影（等比缩放），设置页预览实时所见即所得，`/map reset` 一键回默认。只改 pose 缩放层倍率，纹理管线（SimpleTexture + .mcmeta 线性过滤）零改动，不碰 v2.5.9 修复的显示链路。对局结束倒计时只留倒计时数字（用户反馈）：小地图下方居中仅显示 m:ss 加粗数字本体，不再携带"对局还有…结束"前后缀；颜色（醒目金 / 末 60 秒红）与全部动效（秒位跳变脉冲、冒号 1Hz 呼吸、紧急段 2Hz 闪烁、归零"对局已结束"）不变。新增配置 `markers.player_marker_size`（0.4~1.0，默认 1.0）与语言键双语；清理死键 `match_timer`。全套 180 用例全绿。

2.5.9 修复玩家图标不显示（纹理管线回归原版）：
v2.5.8 的玩家导航箭头在实机地图上不显示（沙箱内静态审计全链路正确但不可复现）——本版彻底移除自研 AbstractTexture + mipmap 链纹理代码，绘制改走原版 GuiGraphics.blit + SimpleTexture 管线（与快捷栏等全部原版 HUD 贴图同一条加载/渲染路径），线性过滤改由原版 .mcmeta 机制声明（blur: true）；纹理缺失时原版回退紫黑棋盘，不存在静默不可见的失败态。图标内容仍为用户 玩家位置图标.svg 原图（纯 #32CD32 平面单色，零再创作，PNG 未变），边缘平滑与视觉尺寸（≈12.5px）与 v2.5.8 设计一致；新增 mcmeta 守卫测试（防打包遗漏），全套 180 用例全绿。

2.5.8 玩家图标严格遵循 SVG 原图：
修复 v2.5.7 玩家导航箭头的三个视觉问题——去掉左半压暗的立体感、去掉中脊近白折痕白缝、去掉腹下软影，图标完全遵循用户提供的 玩家位置图标.svg 原图（纯 #32CD32 平面单色导航箭头，零再创作）；渲染从无抗锯齿的几何三角改为纹理绘制：SVG 原图离线栅格化为 256×256 抗锯齿 PNG 打包进 jar（v2.5.9 起绘制管线回归原版，纹理与视觉不变）。视觉大小与 v2.5.7 一致（形状高 ≈12.5px，不再变大）。

2.5.7 玩家图标换导航箭头：
小地图/大地图/设置预览的玩家位置图标依用户提供的 SVG 设计稿换为现代极简导航箭头：单尖头四边形（尖头顶点 + 双后角 + 后缘凹口），主色取设计稿原色 #32CD32（右半翼）+ 同色压暗 18% 左半翼折纸受光 + 中脊近白折痕 + 腹下软影；整体高 12.5px，较 v2.5.6 纸飞机（16px）缩小约 22%（应用户"小一点"反馈）。
移动动效优化：三处渲染入口（小地图/大地图/设置预览）改喂 partialTick 插值坐标与朝向——图标与尾迹位置消除 20Hz tick 台阶与整数取整台阶（亚像素连续移动），速度估计从"边界尖峰/帧间零速"锯齿变为连续值（拉伸与尾迹强度更稳）；平滑时间常数 140ms→120ms（输入噪声降低后滤波可以更轻，转向与拉伸更跟手）。
联动 API（v2.5.7）：新增统一门面 `dev.draginventory.client.map.TacticalMapApi`——外部标点（稳定 ID + 自定义存活时长 + 独立 16 名额，不占玩家手动 5 名额，自动进入大地图/小地图/世界 HUD/方位条全部视图）、标点事件监听器（ADDED/REMOVED/EXPIRED/CLEARED，异常隔离）、对局倒计时扩展（加时/减时、截止时刻对表、Provider 自省、"对局结束"沿回调——停止 off 不误触发）、POI 提供者注销、编程式地图开关；`TacticalMarker` 升级逐标点 TTL（玩家手动标点仍默认 60 秒，行为不变）。接口详细文档见 wiki《战术地图API》。

2.5.6 玩家图标现代化与移动动效：
小地图/大地图/设置预览的玩家位置图标从像素阶梯风重做为现代极简纸飞机：保留“后缘 V 缺口等腰三角”形制与青绿主色，改用平滑三角几何绘制（告别阶梯锯齿），左右翼同色明暗差模拟折纸受光，中脊近白折痕线，机腹低透明度软影。新增移动动效：转向平滑跟随（140ms 时间常数，跨 ±360° 走最短弧）、速度感知弹性形变（沿机头方向最多 +30% 拉伸 / 横向 -12% 收窄，8 格/秒饱和）、身后两枚渐隐缩小的尾迹残影（120/260ms 前采样，快跑更明显，切后台断流保护不跳残影）、静止时 1.8% 呼吸；大地图玩家图标周围多余的 21×21 半透明方框移除（用户反馈）。新增 PlayerMarkerFX 纯逻辑动效类与 15 组单测断言（全套 168 用例全绿）。

2.5.5 对局计时实装与缩放范围调整：
小地图计时行从静态占位升级为真实倒计时：进入世界按默认时长（10 分钟，`/map timer default <时长>` 可改）自动开始，`/map timer <时长>` 随时手动对表（支持 25:00、1:30:00、30m、1h30m、90s 等写法，纯数字按分钟计），`/map timer reset` 重置、`/map timer off` 关闭；整行加粗，时间值为醒目金色，最后 60 秒转红并加速闪烁，每秒秒位跳变时脉冲放大 + 冒号呼吸（时间流动感），归零显示红色"对局已结束"；对局系统实装后注册 `MapMatchTimer.Provider` 即自动接管真实剩余时间。
大地图缩放范围改为 108%~600%（旧 17%~533%）：旧默认 0.25/8.0 的存量配置首次加载自动收敛到新默认，玩家自定值不动；`/map info` 汇总增至十项（新增对局计时）。

2.5.4 启动自检日志（排障锚点）：
主类构造完成时输出一条 INFO banner（`Drag Inventory construct ok: version=2.5.4 ...`）——2.5.3 一次实机排障（整合包卡红色加载界面）中本模组在日志里零输出、无法自证加载推进阶段；该 banner 与 MapConfig 的 marker 日志共同覆盖"construct → config"链路。本版无任何功能/视觉/行为变更。
背景与结论（详见 releases/v2.5.4/VALIDATION.md）：该次"卡红色加载界面"经生产环境复现对照确认为整合包内 GWO 模组的联网素材校验（api.playgwo.com）在网络不可达时阻塞资源加载所致，与本模组无关；遇同类卡死优先换网络环境重试并清理 mods 内同名双版本 jar。

2.5.3 键位标签/小地图尺寸/快捷键说明/滤镜四项反馈：
按键绑定标签澄清：原版按键绑定列表（Drag Inventory 分类）中“打开战术地图”改名“开/关大地图”、“地图界面开关”改名“开/关大地图界面显示”、“清除标点”改名“清除地图标点”（此前玩家按“大地图”检索不到打开大地图的键位）；M/C 两个绑定补充 IN_GAME 冲突上下文（与原版游戏内按键同口径，冲突检测更准确，屏幕内 M 关图行为不变）。
小地图默认尺寸 128→96（反馈默认过大）：老配置一次性自动收敛——首次加载检测到仍为旧默认 128 时自动改为 96 并落盘（minimap.size_retuned 内部标记，此后自改尺寸被尊重）；设置 GUI 里仍可 64~256 随意调整。
右下角快捷键说明写全且两种模式一致：完整界面与清屏模式共用同一条说明（清屏模式此前只提示“按 H 显示界面”），字号 0.7→0.6，内容补全到全部操作——M/ESC 关闭、左键拖动、右/中键标点、滚轮缩放、空格居中、1/2/3 标点类型、H 界面开关、C 清除标点（两个键名动态跟随当前绑定）。
六种滤镜预设全部重做向原游戏地图风格对齐：烘焙管线新增 S 曲线（暗部更沉亮部更亮、无色阶反转）、地面目标色（三角洲暗蓝黑地面/塔科夫米黄纸面/暗区墨绿底/PUBG 暖褐大地）、墙体目标色（冷白/暖米白/中性灰白，与地面形成强反差二值化观感）；房门青绿与楼梯暖金的战术强调移到滤镜之后（旧版在滤镜前会被去饱和冲淡，三角洲下房门几乎变灰），任何滤镜下门恒为亮青绿、楼梯恒为暖金；默认彩色预设不变，切换滤镜即时全量重烤。

2.5.2 小地图修复与楼层自动跟随（七项反馈）：
小地图消失与错误材质修复：瓦片纹理 ID 改为跨实例全局唯一（旧版小地图/大地图/设置预览三个渲染实例的同名纹理会互相覆盖，触发异常后小地图在本会话内永久停用，或显示为错误材质）；小地图 HUD 的异常熔断从“本会话永久停用”改为可恢复（10 秒冷却自动重试、连续 3 次才永久停用），且切换世界后自动复位（修复“旧游戏显示一会后消失、新游戏不显示、设置里重开也没用”）。
设置 GUI 行为页重排：小地图开关/缩放/尺寸三行提前且尺寸滑条完整可见可点（旧版末尾缩放滑条与底部按钮重叠）；小地图尺寸在 GUI 内即时生效。
图例与标点管理弹窗从画布左侧伸出（位置对标 2.4.0 的左侧面板，占位更小：210×240 浮出面板，开启时 180ms 滑入动画）。
楼层恒定自动跟随玩家：移除手动调整显示层的全部入口（工具栏上层/下层按钮、PgUp/PgDn/Home 键、设置页手动楼层、/map floor 子命令与 auto_floor/manual_floor_y 配置）；小地图与大地图共享同一份楼层目录、显示同一层，自动层防抖（死区+迟滞）沿用 2.5.1。
快捷键全面主键盘化（照顾小配列键盘）：地图内仅用 M/ESC/H/C/1/2/3/空格/滚轮，数字键 1/2/3 本就是主键盘数字（小键盘数字不响应）；底部快捷键说明补全 1/2/3 标点类型切换。

2.5.1 错误修正（对 2.5.0 升级用户的关键修复）：
配置迁移重做——新增 general.migrated 标记，首次加载一律把旧版残留的 enabled=false 复位为开启（2.5.0 重发版的“旧结构特征”迁移在玩家运行过任一版 2.5.0 后失效，残留的关闭状态继续静默禁用 M 键与小地图，这正是“所有 UI 不显示”的元凶）；此后主动执行的 /map off 被尊重。
取消“打开即清屏”默认：清屏模式改为配置项 general.clean_on_open（默认关），打开地图默认显示完整界面；设置 GUI 视觉页新增开关，地图内 H 键行为不变。
数字键 1/2/3 切换标点类型、C 键清除标点时底部居中弹出短暂反馈（修复“按了没反应”的观感）。
地图闪烁修复：楼层 id 从目录下标改为 floorY（目录重建不再误判换层），自动换层加迟滞（候选层不比当前层更近时不切换），静止玩家楼层重扫描从 2 秒降频到 10 秒（消除周期性卡帧），小地图楼层跟随加 ±2 死区防抖。

2.5.0 战术地图改版彩色底图与清屏模式：底图按真实方块颜色实时采样成图（Xaero 世界地图风格），保留方块像素结构与瓦片烘焙管线，房门/楼梯保留战术强调色，深坑与阻挡自动压暗；滤镜改为六种预设（关闭=彩色/三角洲/塔科夫/暗区突围/Apex/PUBG），默认彩色不滤镜。
清屏模式（当时默认开，2.5.1 起改为默认关的可选项），只显示地图、玩家与标点，按 H 或右侧眼睛按钮唤出完整界面，清屏时右下角小字提示。
界面精简：图标按钮从 24 缩小到 18 像素，移除左侧面板，图例与标点管理合并到右侧工具栏第一个按钮的弹窗，完整快捷键说明缩小后移到右下角。
地图右键可放置地点/敌情/物资三种标点，数字键 1/2/3 切换类型，C 键一键清除全部地图标点。
新增左上角常驻方形小地图：跟随所在楼层，深色边框与四角角标、北向指示与玩家朝向箭头，菜单可开关、缩放 0.5~4.0、尺寸 64~256 可调；小地图下方显示对局倒计时占位，MapMatchTimer 接口供对局系统接入真实剩余时间。

## 战术标点操作

- 游戏内中键单击立即生成白色菱形地点标点，不再等待双击窗口；若命中掉落物，则显示该物品的原生图标。中键在正常游戏视角下替代原版“选取方块”，菜单和背包中的中键沿用原行为。
- 450 毫秒内双击，第二次准星对准任何地方都会生成红色感叹号敌人标点，包括地面、墙面、掉落物和任何生物。按第二次点击位置升级首次标点，不额外留一个普通标点。
- 敌人标点作为手动敌情提示，不检查生物敌对关系。第二次点击未命中实体或方块时，在当前视线方向128格处放置敌人标点；单击天空仍不产生地点标点。
- 初始射线范围 128 格，仅选取已加载、射线可见的目标，方块遮挡会阻止选取后方实体。敌人标点固定在点击命中的世界位置，与普通地点标点一样；掉落物标点仍跟随物品，拾取后清除。标点不会因遮挡而隐藏。
- 相机与标点的欧几里得距离向下取整，1 方块 = 1 米，格式如 `12m`。使用游戏实际视图/投影矩阵，适应 FOV、瞄准缩放、镜头倾斜和 GUI 比例。
- 准星距标点 75 个 GUI 单位以内平滑淡化，中心最低不透明度 20%；距离文本和物品图标一起变化。物品图标沿用原版/资源包/模组的原生物品渲染，三维方块也可淡化。
- 标点生成或刷新后按实际时间保留 60 秒，打开菜单仍计时。同一实体以 UUID 去重，同一方块表面重复标记也会刷新；单击地点再双击同一实体会替换为敌人标点。
- 掉落物拾取、销毁或卸载后，于客户端收到更新的下一帧移除对应物品标点。固定的地点和敌人标点持续 60 秒，或在超过 5 个时被最早优先替换。退出世界、切换维度、玩家重生会清空，背包/聊天/暂停/隐藏 HUD 时不绘制或接受新的标点。
- 地点、敌人、物品共用 5 个名额。新目标挤出最早加入者，重复目标刷新不会改变加入顺序；双击升级按一次最终写入处理，换目标不会误删除旧标点或连续挤出两项。新建/刷新时，图标、距离和边缘箭头同步播放 320 毫秒非线性出现动画：55% 缩放起步，略微放大回弹到 100%，从下方 8 个 GUI 单位上移，前 130 毫秒淡入；与准星靠近时的淡出叠加。
- 当前为本机客户端标点，不广播给队友，也不跨世界保存。

## 安装

将 `drag-inventory-1.21.1-neoforge-2.6.1.jar` 和 `ldlib2-neoforge-1.21.1-2.2.40-all.jar` 放入游戏实例的 `mods` 文件夹，移除旧版 Drag Inventory JAR。
不要把源码 ZIP 或 sources.jar 放进 mods。LDLib2 前置沿用 1.2.x，开发与测试固定使用 2.2.40。
单人游戏无需额外设置；联机时服务端和客户端都需要本模组的 2.6.1 JAR，以同步体力、执行行动限制并应用真实的 100 生命值规则。独立服务端不需要 LDLib2（依赖仅限客户端）。方位条 HUD 为纯客户端功能，服务端不参与。轮盘左键提交使用原版当前持有栏位数据包，服务端使用实际选中的第 5–9 格。

## 生命值与体力条

- 玩家基础最大生命值设为 **100 点**（原版为 20 点），新玩家及死亡重生后满血为 100。
- 登录时若存档保存了其他基础上限，会改为 100 并保留当前血量比例；已是 100 上限时登录不会回血。
- 药水、装备等属性修饰符继续生效，因此生命提升效果可让最终上限超过 100；不改伤害和食物机制。
- 血条位于左下角，使用白色细长填充条；左侧为玩家当前皮肤的 2D 头像，下方为玩家名字。没有数值、加号、标题或装饰面板。长名字自动缩小以完整显示。
- 删除黄色饥饿条，改为位于五格快捷栏上方、与其等宽的白色体力条；没有数字、图标或标签。两条状态条共用细边框、深色空槽和白色填充样式。
- 消耗/受伤后平滑缩短，原填充位置的淡灰色尾迹自然收拢；恢复时平滑增长。体力不超过 20% 时填充变为红色，恢复超过 20% 后恢复白色。
- 头像血条随窗口宽度缩短，极窄界面时上移少许，避免与快捷栏、副手重叠。
- 体力上限 **100**，实际移动中的疾跑每秒消耗 **12**，每次跳跃消耗 **10**；停止消耗约 **2 秒（40 游戏刻）**后每秒恢复 **16**（按正常 20 TPS 计）。走路和站立不消耗；原地保持疾跑标记不扣体力。
- 创造、旁观、飞行、鞘翅滑翔、乘坐和睡眠不消耗体力。体力不会小于 0 或大于 100；存档保存当前体力，死亡重生恢复至 100。
- 红色区间（体力大于 0 且不超过 20）：不能开始新的疾跑，但已经进行的疾跑继续消耗至 0 才中断；仍可跳跃，剩余不足 10 时也允许完成一次跳跃并耗尽剩余体力。
- 体力为 0 时中断疾跑，同时禁止开始疾跑和起跳。恢复到大于 0 后可跳跃，恢复到大于 20 后可重新疾跑；不需要等到回满。
- 被禁止的操作不会扣体力，也不会重置恢复等待时间；再次成功跳跃或疾跑消耗才重置 2 秒等待。普通移动、碰撞、饥饿等原版停止疾跑条件继续生效。
- 疾跑启动和跳跃入口在客户端与服务端都检查体力。原版食物、饥饿、冲刺条件和自然回血规则仍然生效，仅隐藏食物显示。
- 吸收生命计入血条比例；创造、旁观和 F1 隐藏状态条。经验条与等级数字继续隐藏。
- 可通过 `StaminaState.java` 调整体力参数，通过 `StatusBar.java` 调整外观和动画。

- 只显示原快捷栏第 5–9 格，隐藏左侧第 1–4 格及所有按键编号；选中格为白边、较亮底色。
- 五格连续排列，每格 24×24，总宽 120 个界面像素，整体居中靠底，距底部 3 像素。体力条与槽位上沿间隔 4 像素。
- 实时读取玩家快捷栏，保留数量、耐久、物品冷却和获得物品动画；副手槽随主手方向调整。
- 隐藏经验条及等级数字，只影响显示，经验获取和消耗规则保持原版。
- 为状态条预留固定高度，护甲、氧气、坐骑血量、骑乘跳跃条及物品名称显示在其上方。
- 滚轮在武器第 1–4 格的非空槽之间循环；数字键 1–4 按非空槽顺序选择，5–9 按原物理槽选择。副手交换沿用原版操作；F1 隐藏快捷栏，旁观模式保留原版旁观菜单。
- 第 1–4 格仅从底部快捷栏隐藏，物品不会删除；剩余五格仍对应原键位 5–9。隐藏格选中时不会高亮其他格。物品堆叠数量继续显示。
- 参考图中的枪械、工具箱等来自对应物品模组，本模组不添加这些物品。
- 可在 `src/main/java/dev/draginventory/client/ReferenceHotbar.java` 调整尺寸、可见槽位、颜色和边框。

## 方位条 HUD

- 顶部中央方位罗盘：0° = 北、顺时针增大；中央高亮当前度数，两侧滚动方位文字与角度刻度。显示视野范围（60°~360°）、刻度间隔、主方向字号、中文方位字全部可调；位置可拖拽或精确偏移，条宽 120~960。完整使用手册见 `wiki/方位条HUD.md`。
- 五套皮肤：`delta`（三角洲，默认）、`pubg`（绝地求生）、`apex`、`battlefield`（战地）、`warzone`（使命召唤），按各游戏原作还原；六组配色（极光/霜白/琥珀/绯红/紫罗兰/石板）可与任一皮肤组合，accent/文字/刻度/背景五通道可逐项覆盖，内置 HSL 取色器。
- 动画：临界阻尼弹簧（无过冲无余振）、359°↔0° 最短路径、亚度精度平滑；方位吸附辅助、惯性倾斜、入场动画均可开关。
- 指令：`/com`（最短别名，无参直接唤出设置界面）、`/compass`、`/herracompass` 三条根指令等价，含 style/palette/offset/scale/opacity/width/range/smooth/markers/test/copy/info/reset 等 18 个子命令；非法参数报错并列出合法值。
- 设置界面（`/com` 唤出）：六页签（外观/布局/显示/标点/动效/颜色）单屏容纳全部选项；顶部实时预览与 HUD 同渲染路径，支持拖拽转向、模拟滑杆、自动摆动；布局页签有全屏拖拽定位、四向快捷对齐、屏宽占比预设；三套菜单主题；每行带单项恢复默认按钮。
- 战术标点联动（只读）：敌对红感叹号、位置白菱形、物资物品贴图自动映射到对应方位，带实时距离/文字标签与平滑脉冲；视野外侧的标点吸附到条带边缘压暗并附方向箭头；屏外更远的不显示。标点颜色与主题高亮色自动撞色规避。
- 死亡标点：死亡自动在落包点生成红色 X（同维度显示），重生后沿方位条导航，活着靠近 8 米自动清除；可开关。
- 独立 HUD 图层注册，与快捷栏、体力血条、枪械 HUD 互不影响；配置写入 `config/draginventory-client.toml`，改动 500 毫秒防抖落盘，设置界面/指令/手改文件三方同步。
- `CompassApi` 联动门面：其他模组可反射读取朝向与角速度、注册标点提供者、监听基数方位进入事件；未安装时安全降级，不抛异常。

## 操作

### 口袋轮盘

- 在正常游戏中持续按住左 Alt 或右 Alt 约 50 毫秒打开，按住期间保持菜单；短按不会打开。
- 五扇区从顶部顺时针对应原物理第 5、6、7、8、9 格，空格仍保留固定位置；屏幕中央是取消死区。
- 松开 Alt 确认高亮物品并关闭；中心 15 屏幕像素死区保留当前候选，无候选时只关闭。按住期间左键按鼠标方向选取扇区立即装备并同步服务端；鼠标在轮盘外也按方向选择，死区内保持当前选择。
- 滚轮向上选择上一格，向下选择下一格，与快捷栏方向一致；滚动改变高亮和轮盘自旋，装备在左键确认或松开 Alt 后提交。鼠标静止时保持滚轮选中的候选，实际移动鼠标后恢复指向选择。
- 右键、Esc、失焦、死亡或被其他界面替换时取消；不会提交半途的悬停选择。
- 轮盘打开时暂停鼠标视角控制，游戏继续运行；关闭后立即恢复鼠标，150 毫秒淡出独立继续播放。
- 打开和淡出期间临时隐藏其他 HUD 图层，避免方位条和快捷栏与轮盘文字重叠；结束后恢复。
- 顶部标题为“口袋”，底部没有操作提示。可在原版“按键绑定”中修改“长按打开口袋轮盘”，支持修饰键。

### GWO 枪械 HUD

- 滚轮只在第 1–4 格的非空槽之间循环；从第 5–9 格滚动时按方向进入最前或最后一个非空武器槽。
- 数字键 1–4 立即选择按顺序排列的非空槽，HUD 按键同步更新；支持在原版按键设置中改绑。创造模式的快捷栏预设保存/加载组合沿用原版。
- 空槽完全省略；非空但缺少可用贴图的物品仍保留按键和短横线。只剩一把武器时，候选行为空，滚轮保持该武器。
- GWO 的原生枪械轮廓、弹匣和备弹信息继续由 GWO 绘制；本模组在上方绘制其余三个武器位的编号、白色贴图及平移动画。当前槽位从候选行中排除。
- 候选贴图自动裁掉透明边缘、保持比例，随 GWO 的屏幕缩放定位；贴图缓存有容量限制，资源重载时释放并重新生成。
- 选择提交与 HUD 动画分离，快速连续输入以最新槽位为准。
- 当前枪械的 GWO 主面板单独做平移和缩放；上方候选行沿用原有平移动画。缩放围绕主面板中心进行，结束后恢复原生尺寸及位置。近战没有 GWO 原生弹药面板，候选行正常显示。
- 底部战术姿态、射击模式和激光使用动态高清键帽；安装激光后才显示激光提示。示例中的 Y 是测试绑定，正式版本始终显示玩家在 GWO 中设置的实际按键，不自动修改绑定。
- 视角、疾跑、跳跃与开火触发轻微 HUD 晃动；以实际经过时间计算，支持不同帧率。位移上限为 GWO 面板坐标横向 7、纵向 8，倾斜上限 1.5 度；HUD 原生缩放继续生效。站立、原地按住疾跑及未实际射击时不会制造随机震动。

| 操作 | 结果 |
| --- | --- |
| 左键短按并原地松开 | 物品保持原位 |
| 按住左键约 180 毫秒，或按住后移动至少 4 个界面像素 | 拿起并拖动 |
| 拖到目标格松开 | 放下、合并同类物品，或交换不同物品 |
| 同一物品格在 250 毫秒内双击 | 执行原版 Shift＋左键的 QUICK_MOVE 快捷移动 |
| Shift＋左键 | 与普通左键相同，不再触发快捷移动 |
| 拖到无效格或界面外松开 | 优先放回来源格，否则尝试放入玩家背包 |

原版双击“收集同类物品”功能被替换。双击只处理当前格，转移方向沿用原容器规则。
左键拖过多个格子不再平均分配，只在松开所在格放置。
右键拆分/逐个放置、Shift＋右键、数字键、F、Q 保留原版行为；正在左键拖动时拦截其他物品操作，避免交叉操作。

## 边界行为

- 背包、箱子、熔炉、工作台等继承原版容器界面的页面使用同一套输入修改。
- 合并后的余量、交换出来的物品优先放回来源格。
- 合成/交易等结果格不能放回时，尝试放入玩家背包。若全部合法格子都没有空间，余量保留在鼠标上，可再用左键放入空格。
- 从原版右键操作留下的鼠标物品，可在目标格按下并松开左键放下。
- 松开到界面外不主动丢弃；需要丢弃时使用原版 Q。关闭界面沿用原版对鼠标物品的处理规则。
- 创造模式目录的 QUICK_MOVE 沿用原版含义：双击目录物品取一整组到鼠标上，与生存模式容器间转移不同。
- 尚未逐项实测创造模式目录、联机和其他鼠标整理模组的组合；完全重写输入处理的第三方界面可能不受本模组影响。

## 构建与测试

安装 JDK 21 后，在源码目录执行：

```powershell
$env:JAVA_HOME = '你的 JDK 21 安装目录'
.\gradlew.bat build
```

成品位于 `build/libs/drag-inventory-1.21.1-neoforge-2.6.1.jar`。
NeoForge 构建版本固定为 21.1.251。发布 JAR 包含通用生命值规则及客户端 HUD/Mixin；自动测试入口不包含在内。

- GWO 原生切枪与开火检查：`.\gradlew.bat runClient -PswitchSmoke`（独立 `run-switch-smoke` 实例，公开 API 注册纯配置测试枪，验证原生时间轴、动作锁、真实子弹/扣弹、换弹锁及射速）
- 输入逻辑测试：`.\gradlew.bat test`
- 轮盘客户端与服务端集成检查：`.\gradlew.bat runClient -PwheelSmoke`（自动使用独立 `run-wheel-smoke` 实例，验证长按开关、短按不触发、点击提交、滚轮预览/自旋、取消和 GUI 缩放，保存六张截图与动画采样 CSV 后退出）
- 战术标点与方位条桥接集成检查：`.\gradlew.bat runClient -PmarkerSmoke`（真实实体、数据包与原生渲染，验证敌对/掉落物/位置标点并截图，然后退出）
- 开发客户端：`.\gradlew.bat runClient`
- 自动启动检查：`.\gradlew.bat runClient -PsmokeTest`
- 游戏内快捷栏检查：`.\gradlew.bat runClient -PhotbarSmoke`（创建独立超平坦测试存档，验证布局与缩放并截图，然后退出）
- GWO 槽位规则和动画状态由 `WeaponSlotsTest`、`WeaponSwitchAnimationTest` 覆盖。
- `WeaponHudMotionTest` 覆盖视角方向与跨 180 度边界、疾跑/静止/空中、起跳落地、开火衰减、叠加限幅、30/144 FPS 一致性以及长帧间隔和切枪清理。`HudMotionSmoke` 在实际客户端转动视角、疾跑、跳跃、开火并录制 HUD，检查变换恢复、回正及打开背包后的复位。
- GWO 实际游戏检查：`.\gradlew.bat runClient -PweaponSmoke -PweaponGameDir=run-weapon-gwo`。需在该隔离目录预先准备合法取得的 GWO 2.12.87、GWO Default Gun Beta1.4 和近战内容包；第三方文件不随源码包分发。检查真实武器、按键 1–9、连续滚轮、白色贴图像素、GUI 2/3/4、空槽、换武器与资源重载，并保存截图。激光检查会装入真实配件，验证按 Y 实际关闭/开启、改绑 K 后的提示及未安装配件的枪械。

启动检查会在界面加载并验证 Mixin 后自动退出；`src/smoke` 只在传入 `-PsmokeTest` 时编译，正常构建不包含自动退出功能。
`src/hotbarSmoke` 和 `src/weaponSmoke` 同样仅用于检查，不包含在正常发布 JAR 中。检查后请用不带检查参数的 `clean build` 生成发布包。

1. Java 21 / Minecraft 1.21.1 / NeoForge 21.1.251 构建成功。
