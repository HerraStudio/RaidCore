# 战术地图（大地图 + 小地图）

> 模组：Drag Inventory · Minecraft 1.21.1 · NeoForge 21.1.251 · LDLib2 2.2.40
> 自 v2.0.0 引入全屏地图，v2.5.x 系列重做为动态彩色底图，当前版本 v2.6.1

按 `M` 打开的全屏工厂战术地图 + 左上角常驻小地图：底图按真实方块颜色实时采样成图（Xaero 世界地图风格），不预渲染、不绑定固定区域——任意已加载地形即时成图；楼层自动跟随玩家，六种滤镜预设向原作风格对齐；右键三种战术标点，导航箭头玩家图标（v2.5.9 严格遵循用户 SVG 原图，原版纹理管线；v2.6.0 大小可调 40%~100%）带全套移动动效，小地图下方居中显示倒计时数字（v2.6.0 起只留 m:ss 数字本体；v2.6.1 归零字样停留约 2.5 秒后消失）。全部选项可经 `/map` 指令与五页签设置 GUI 调整，即时生效。

## 快速上手

1. **安装**：把 `drag-inventory-1.21.1-neoforge-2.6.1.jar` 和 LDLib2 2.2.40 放进 `mods` 文件夹。
2. **打开大地图**：进世界按 `M`（或聊天栏 `/m` 回车）。
3. **对表**：进入对局时 `/map timer 25:00`（或 `30m`）设定本局时长；想一劳永逸就 `/map timer default 30m`，以后每次进世界自动倒计时。
4. **放标点**：大地图上右键放当前类型标点，`1`/`2`/`3` 切换地点/敌情/物资，`C` 清除全部。
5. **调外观**：`/map gui` 打开设置界面，或 `/map filter tarkov` 一键换滤镜。

> 底图按真实方块颜色采样：你世界里是什么颜色，地图上就是什么颜色（房门青绿、楼梯金黄两处战术强调除外）。未加载的区块显示深色底幕，走近加载后自动成图。

## 大地图界面

默认打开即**完整界面**（顶栏 + 工具栏 + 右下读数）；设置视觉页可改为"打开时进入清屏模式"，地图内 `H` 随时互切。

- **顶栏**：当前楼层 Y 大字 + 楼层标签组（最多 6 枚，活动层高亮）+ 中央北向指示 + 右上关闭按钮。
- **右侧工具栏**（4 枚 18×18 按钮）：图例与标点管理（弹窗）、清屏切换（眼睛）、定位（回到玩家）、设置。
- **图例+标点管理弹窗**：工具栏首键唤出，从画布**左侧**伸出（210×240，180ms 滑入）——上半部八语义图例，下半部三类标点行（含数量徽标）、显示开关与清除按钮。
- **右下角**：缩放按钮对 + 自适应比例尺 + 悬停坐标与缩放百分比 + **全套快捷键说明**（0.6 缩放暗色小字，键名随改键动态显示，清屏模式同样显示）。
- **操作**：左键拖动平移；滚轮以鼠标为锚缩放；空格或定位按钮回玩家；不暂停游戏。

## 小地图

左上角常驻方形 HUD（默认 96 像素，64~256 可调），打开任意界面（含大地图、聊天）或按 F1 时自动隐藏，`/map off` 连同大地图一起关闭。

- **与大地图同层同源**：共享同一份楼层目录，恒定显示玩家所在层（v2.5.2），换层不闪烁。
- **合成层零开销**：不做独立扫描，直接复用大地图的解析结果，瓦片独立缓存（与大地图互不干扰）。
- **战术外观**：深色边框 + 四角青绿角标 + 顶部 N 北向指示 + 居中的导航箭头（v2.5.9 SVG 原图，#32CD32 平面单色，大小可调 v2.6.0，移动动效见下节）；大地图放的标点按楼层 ±3 过滤同步显示（5×5 类型色块）。
- **异常自保**：渲染异常自动熔断 10 秒并记日志（连错 3 次才永久停用本会话），绝不波及游戏本体与其他 HUD；换世界自动复位。

## 玩家导航箭头（v2.5.9）

小地图、大地图与设置页预览共用同一枚玩家图标：**单尖头四边形导航箭头**（尖头顶点 + 双后角 + 后缘凹口），v2.5.8 起严格遵循用户提供的 玩家位置图标.svg 原图绘制（前身为 v2.5.6 纸飞机、v2.5.7 几何重绘）——**纯 #32CD32 平面单色**，无明暗差、无折痕、无软影，所见即原图；原图离线栅格化为 256×256 抗锯齿 PNG 打包进 jar。v2.5.9 修复实机不显示问题：绘制彻底回归原版管线——`GuiGraphics.blit` + SimpleTexture 纹理加载（与快捷栏等全部原版 HUD 贴图同一条路径），线性过滤（无锯齿）由原版 `.mcmeta` 机制声明（`blur: true`），**任意 GUI 缩放/呼吸/拉伸下边缘平滑如矢量**（SVG 本来的观感）；纹理缺失时原版回退紫黑棋盘，游戏内一眼可辨。视觉大小与 v2.5.7 一致（形状高 ≈12.5px，不再变大）。

**大小可调（v2.6.0）**：设置界面（`/map gui`）标点页“玩家图标大小”滑条或 `/map player_size <0.4~1.0>` 调整——1.0 = 默认尺寸（上限，即 ≈12.5px），最小 40%（≈5px）；作用于小地图/大地图/设置预览与尾迹残影（等比缩放），设置页预览区实时所见即所得，`/map reset` 或“恢复默认”一键回 100%。

移动动效（全部自动，无需配置）：

- **插值移动**（v2.5.7 优化）：图标与尾迹按渲染帧 partialTick 插值坐标移动——非 tick 台阶、非整数像素，任意缩放下匀速平滑；速度估计连续，拉伸与尾迹强度不再锯齿。
- **平滑转向**：转身时图标平滑跟随（120ms 时间常数，v2.5.7 从 140 调低——插值输入后更跟手，最短弧跨 ±360°），不再瞬跳。
- **弹性形变**：速度感知——沿前进方向最多拉伸 +30%、横向收窄 -12%（8 格/秒饱和，疾跑/骑马刚好拉满），有空气动力学感。
- **渐隐尾迹**：移动速度超过 1.2 格/秒时身后出现两枚渐隐缩小的残影（120ms 与 260ms 前的轨迹采样），越快越明显；潜行级慢速不触发。
- **静止呼吸**：停下后轻微呼吸（1.8% 缩放、2.4 秒周期），一动就开始就淡出（位置精确优先）。
- **断流保护**：切后台/卡顿恢复后残影不会跳到远古位置；换世界自动重置。
- 大地图上原包围图标的 21×21 半透明方框已移除（v2.5.6），仅保留图标本体。

## 对局计时

小地图下方居中显示倒计时数字（v2.6.0 起只留 m:ss 数字本体，不再携带"对局还有…结束"前后缀），v2.5.5 起为**真实倒计时**（此前是 10:00 静态占位）：

- **自动开始**：每次进入世界按默认时长（600 秒 = 10:00）自动开始；`/map timer default <时长>` 修改默认并持久化（如 `default 30m`）。
- **手动对表**：`/map timer 25:00` 立刻按 25 分钟重新倒计时——进对局按实际开局时间对一次表即可。支持三种写法：冒号式 `25:00` / `1:30:00`，后缀式 `30m` / `90s` / `1h30m`，纯数字按分钟计（`25` = 25 分钟）。
- **其他操作**：`/map timer` 查看状态；`/map timer reset` 重置为默认时长；`/map timer off` 关闭（下次进入世界自动恢复）。
- **视觉设计**（本版重点）：数字本体**加粗**、**醒目金色**；**最后 60 秒转红**并加速闪烁；每秒秒位跳变时数字整体**轻微脉冲放大**，冒号 1Hz **呼吸明暗**——倒计时"活"了起来；归零后显示红色"**对局已结束**"（v2.6.1 起停留约 2.5 秒后整行消失，不再常驻）。
- **对局系统联动**（预留）：模组读不到 GWO 服务器的对局剩余时间（服务器不下发），故采用手动对表方案；对局系统实装后实现 `MapMatchTimer.Provider` 并注册即自动接管真实值，渲染层零改动——接口详细文档见 [战术地图 API](战术地图API.md)。
- 计时基于真实时间戳（deadline 制）：暂停菜单、掉帧都不影响走表，符合对局计时的真实语义；维度切换视为新对局，自动重置。

## 战术标点

- **放置**：大地图上右键或中键点击已加载地形，放置**当前类型**标点；类型三种——地点标记（蓝）/ 敌情标记（红）/ 物资标记（黄），数字键 `1`/`2`/`3` 切换（弹窗内亦可点选），切换与小地图同步生效。
- **反馈**：切换类型与 `C` 清除时底部居中弹出短暂通知（修复"按了没反应"的观感）。
- **显示**：默认战术 glyph 风格（`/map marker style minimal` 换小圆点）；显示距离标注与剩余寿命倒计时可开关；清屏模式下标点**不隐藏**。
- **规则**：与世界 HUD 战术标点共用 5 个名额、60 秒生命周期；小地图上按楼层 ±3 过滤显示。联动系统可经外部标点 API 放置独立名额的标点（稳定 ID + 自定义存活时长，见 [战术地图 API](战术地图API.md)）。
- **清除**：`C` 键（游戏内或地图内均可）或弹窗"清除全部标点"按钮。

## 楼层系统

- **恒定自动跟随**（v2.5.2 起唯一模式）：活动层永远跟随玩家所在楼面，无任何手动调层入口。
- **双防抖**：层高跨度一半为死区（±span/2，楼梯中途不抖动）；出死区后候选层必须更近才切换（迟滞），目录重建的层集合抖动不再引发闪烁。
- **稳定层身份**：楼层 id = floorY（跨目录重建稳定），换层时顶栏闪烁提示。
- **扫描**：移动时每 40 tick、静止时每 200 tick 或水平移动超 32 格重建楼层目录（半径 64~512 格可配）；相近楼面 |ΔY| ≤ 3 合并，最多 16 层。
- **历史**：v2.5.2 移除了手动层全套（PgUp/PgDn/Home 键、工具栏上下层按钮、`/map floor` 子命令）——见 v2.5.2 反馈⑤。

## 滤镜预设

设置视觉页六块预设一键切换，或 `/map filter <id>`；切预设即时全量重烤。v2.5.3 全部重做向原作地图风格对齐：

| id | 名称 | 风格 |
| --- | --- | --- |
| `none` | 关闭(彩色) | 真实方块本色，默认 |
| `delta` | 三角洲 | 暗蓝黑地面 + 冷白建筑，门青绿楼梯暖金强调 |
| `tarkov` | 塔科夫 | 米黄纸面 + 暖米白墙体 |
| `darkzone` | 暗区突围 | 墨绿地面 + 中性灰白墙 |
| `apex` | Apex | 提亮增饱和 |
| `pubg` | PUBG | 自然暖褐大地 |

管线：亮度 LUT + S 曲线 → 饱和度 → 全局染色 → 地面目标色 → 墙体目标色 → 门/楼梯滤镜后恒定强调（任何滤镜下门恒亮青绿、楼梯恒暖金）。

## 缩放与视野

- **范围 108%~600%**（v2.5.5 应用户反馈调整；屏幕百分比 = 缩放/1.5×100）：`zoom_min` 默认 1.62、`zoom_max` 默认 9.0。
- **滚轮**以鼠标位置为锚缩放（清屏模式下满屏可用）；**右下 +/- 按钮**以画布中心为锚；`空格`/定位按钮回玩家。
- 打开地图默认 100% 视角（低于新最小值时自动收到 108%）；`follow_player=false` 时跨开关屏记忆上次视野。
- 视野中心钳制在楼层目录范围 ±96 格内，允许略微出界平移、不会漂移到无穷远。
- 旧版升级用户：旧默认 0.25/8.0（17%~533%）的配置首次加载自动收敛到新默认；自定过其他值的用户不受影响。

| 页签 | 内容 |
| --- | --- |
| 楼层 | 扫描半径滑条、层高跨度滑条、说明行 |

| 标点 | 风格、显示、放置类型、距离标注、倒计时 |

顶部实时预览：迷你地图（独立坐标变换）+ 九语义色样例 + 不透明度/滤镜读数。改动防抖落盘，关屏兜底写盘。

## 指令参考

`/herramap` 与 `/map` 为等价完整子树，`/m` 为快捷别名；无参均直接打开大地图。全部为客户端指令，无需权限；非法参数报错并列出合法值。

| `/map opacity <0.3..1.0>` | 整体不透明度 |

| `/map zoom max <2.0..16.0>` | 最大缩放（默认 9.0 = 600%） |

| `/map follow <on\|off>` | 打开时居中玩家（关闭时记忆视野） |
| `/map marker style <tactical\|minimal>` | 标点风格 |

| `/map marker distance` / `countdown <on\|off>` | 距离标注 / 标点倒计时 |
| `/map player_size <0.4..1.0>` | 玩家图标大小（1.0 = 默认 = 上限，反馈按百分比显示；v2.6.0） |
| `/map reset` | 全部恢复默认 |
| `/map info` | 十项汇总：模式/楼层/滤镜/不透明度/小地图/标点/图层/缩放/扫描半径/对局计时 |

## 按键绑定

## 常见问题

**打开地图看不到任何 UI？**
v2.5.1 起默认完整界面；若曾开启"打开时进入清屏模式"，按 `H` 或右侧眼睛按钮唤出完整界面。

**地图闪烁 / 中心一直闪？**
v2.5.1 已根因修复（层 id 稳定 + 迟滞 + 静止降频扫描）。若仍出现，调大 `/map span`（死区更宽）。

**小地图消失 / 材质错乱？**
v2.5.2 已根因修复（纹理 ID 全局唯一 + 熔断可恢复）。极端情况下小地图自动停用 10 秒后自愈，连错 3 次才停用本会话，换世界自动复位。

**计时一直是 10:00 不动？**
v2.5.4 及以前为静态占位；升级到 v2.5.5 即为真实倒计时，或用 `/map timer <时长>` 手动对表。

**倒计时和服务器对局时间对不上？**
模组读不到服务器内部时间（不下发），需进对局时 `/map timer 25:00` 手动对一次表；对局系统实装后会自动接管。

**地图上放不了标点？**
只能放在已加载地形上（未加载区域是深色底幕）；标点与世界 HUD 共用 5 名额、60 秒过期。

**M 键没反应？**
`/map off` 会连同关闭 M 键与小地图（地图关闭时按键会提示），`/map on` 恢复；也检查按键绑定是否被其他模组占用。

**滤镜太暗/不像原作？**
v2.5.3 六滤镜按原作逐套调过参（S 曲线 + 地面/墙体目标色），可 `/map filter` 逐个试；不喜欢就 `none` 用彩色本色。

**联机需要服务端装吗？**
地图为纯客户端功能；但模组整体的体力/生命规则要求服务端同装（详见主 README 安装章节）。
