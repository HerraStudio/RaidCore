## v1.0.17 — LDLib2 战术破译小游戏

- F 打开 LDLib2 战术圆环界面，种子生成绿区与匀速指针，空格/左键节奏判定。
- 成功 3 次解锁、绿区 60°→45°→30°、逐步加速；失误 3 次失败冷却 3 秒。
- `@DescSynced` 字段同步，服务端按会话/修订/序号/实时时钟重算，拒绝客户端伪造结果。
- 破译期间锁定移动、使用、武器切换与 GWO 开火/换弹等入口；附近机械噪音、伤害抖动及概率中断。
- 高价值奖励一次生成箱内，满箱保留待存奖励；拆放已解锁箱不能刷新，成功后开门进入原搜刮。
- LDLib2 成为双端必需依赖；保留原背包和开门功能。
## v1.0.16 — Blender 开门动作与永久开启标记

- 经本机 Blender Lab MCP 在 Blender 5.2.2 制作动作，保留可编辑 `.blend` 和带 1 个动作的 GLB，导出闭合箱体/门模型及真实曲线。
- 默认关门，首次交互播放 16 tick 开门动作后打开搜刮；门、把手、锁具共同转动，箱体保持不动。
- 开启后不再关闭；退出界面仍敞开，所有玩家可见，方块状态持久化，重启/后加入客户端直接显示开启。
- 后续交互立即打开原搜刮，保留 27 格容量和物品存储/掉落。
- 58 项单元测试与实际交互、动画中间帧、延迟界面、永久开启、保存回读和后续访问检查通过。

- 接入 avhatar 的 Simple Safe（CC BY 4.0），原始箱体、门、把手、锁具与基础颜色贴图保留，包含作者署名与改动说明。
- GLB 静态节点转换为 NeoForge 原生 OBJ，世界方块、物品图标、手持及掉落物共用模型，不增加 GLB 加载模组依赖。

- 移除石头占位模型及占位方块实体渲染器。保持 27 格存储、搜刮界面、保存及破坏掉落。
- 55 项原有单元测试及原生模型/物品/四向/存储/搜刮/掉落检查通过。

## v1.0.14 — 搜打撤对局框架

- 通过管理命令配置大厅、轮换出生点及方形撤离区，玩家 `/raid join` 进图出生。
- 接入用户制作的 Photon 绿色烟雾原始导出；附近区域独立持续播放，换维度、资源重载和断线清理。
- 默认连续停留 20 秒撤离；离开、换区或改变计时长度重置进度；顶部数字计时、虚线分隔、进度条与淡入滑动/脉冲动效。
- 撤离保留战利品并返回大厅，死亡正常复活后返回大厅；结算显示结果、战区、行动时间、击杀数。
- 对局内死亡保留近战武器，其余装备/物资掉落，覆盖 keepInventory；储物区近战因装备掉落进入待整理区。
- 服务端权威判定，真实死亡路径提交，避免复活模组取消死亡时提前结算；配置、会话和最新结果按世界保存。
- 断线/重启中断未完成对局，重登返回大厅，同一结算只确认一次；修复结算被其他界面替换后丢失和确认被拒绝后的重试。
- 客户端新增 Photon 2.2.7+（2.2.x）依赖，原背包拖拽逻辑和数据格式保持。

## v1.0.13 — 首个 GitHub Release

### 战术背包

- 武器、装备、胸挂、背包和五个口袋的独立布局；物品按真实占格尺寸放置，保留图标、数量和全部 ItemStack 组件。
- 多格物品从整体左上角记录抓取偏移，悬浮、高光和放置共用同一根坐标。
- 胸挂、口袋和背包使用连续网格、实时容量条及军事蓝灰磨砂背景。

### 替换与旋转

- 支持一次覆盖并回填多件物品，优先保留相对布局，必要时自动寻找位置、旋转和回溯。
- 可行布局显示绿色，无法回填显示红色；服务端一次性提交或拒绝整笔操作，保留数量、弹药和其他组件。
- 当前首选方向放不下时自动尝试另一方向，回到可用位置恢复首选；图标与占格同步旋转 90°。
- 保留拆分、合并、R 手动首选方向、Shift 转移、类型限制、装备容量保护和灰色来源遮罩。

### 搜刮

- 支持保险箱、原版箱子、双箱、陷阱箱及木桶；自动逐件揭示，隐藏物品不可提前取走。
- 支持背包与搜刮区之间的拖放、替换、旋转与拆分，校验距离、修订号、物理槽数及堆叠上限。

### 验证

- 44 项单元测试通过，包括 300 个小布局与独立穷举算法对照。
- 14 类原生游戏检查通过，包括真实鼠标、网络包、跨容器替换及组件保留。

需要 Minecraft 1.21.1、NeoForge 21.1.251、GWO 内部版本 2.12.87；客户端需要 LDLib2 2.2.40。联机双方都应更新本版。
