# 游戏内搜刮管理

2026-10-05，Minecraft 1.21.1 / NeoForge 21.1.251。扩展既有搜刮、物品配置与背包界面。

## 配置入口

背包顶部的“搜刮管理”进入统一入口，管理员也可输入 `/tacticalloot`。管理页提供“容器”和“物品 / 爆率”两个入口；物品页沿用原稀有度、宽高、旋转预览和图标，只增加基础爆率及掉落池开关。非管理员可查看，保存由服务端检查 OP 2 权限。

容器页默认列出所有已安装模组注册的非空气方块，不局限于原版容器。可搜索名称、方块 ID 或模组 ID，或者通过“准星方块”“手持方块”直接选中。开启“允许 F 搜刮”，设置名称与系数，再保存同步。

例如用户截图中的末日装饰板条箱：搜索 `doomsday_decoration:acrate_2`，设为可搜刮容器，即使它没有方块实体或原生库存也可以使用。注册以方块类型为单位；同类型的方块应用相同名称与系数，库存以世界维度和坐标分别保存。末日装饰仅作为实际兼容测试，不是 RaidCore 新增的必需依赖。

## 爆率和物品池

在原物品配置页选择物品或具体 GWO 型号，设置“基础爆率 %”，启用“加入搜刽物品池”并保存。左侧“只看搜刽物品池”可筛选已启用物品。稀有度和大小继续通过原配置调整。

每个已加入池的条目独立进行一次判断：

```text
最终爆率 = min(100%, 基础爆率 × 容器系数)
```

基础爆率范围为 0–100%，容器系数为 0–100。系数 1 保持原概率，0.5 减半，2 加倍，0 不生成新的物品。示例：钻石基础 25%，板条箱系数 4，该条目的判断概率为 100%。每次成功生成一件；当成功条目超过可用容量时，随机打乱后放入，避免按配置顺序偏向前面的物品。

基础版 GWO 通用枪/近战物品不能作为未指定型号的掉落物；请选择实际型号。物品池生成使用真实服务端注册和 GWO 初始化，不使用编辑器的预览物品。

## 库存和交互

准星对准已启用容器，在准星下方显示当前搜刮按键、`搜刮` 和容器名称。F 默认打开原来的搜刮界面，保留逐件揭示、占格、拖放、旋转和存取流程。未启用方块沿用自身交互；已启用容器的右键打开被拦截。

箱子、木桶、潜影盒及保险箱默认启用。箱子与木桶保留原库存、开合和查看人数；双箱对合并库存进行一次物品池判断，不会对两半重复生成。其它有原生库存的方块通过现有 `LootSession` 适配，没有原生库存的方块使用 27 格共享库存。已放入的物品保留，不清空容器或替换原方块。

当尚未配置任何掉落池条目时，原容器继续沿用其战利品表；普通方块可打开空搜刮库存，不会提前耗掉生成机会。配置池后，未生成容器首次搜刮应用新规则。原容器尚未展开的战利品表由配置池接管，已存在的内容保留。保险箱仍需完成原破译流程，配置池替代新破译奖励的生成；未配置池时保留原奖励表。

生成标记、空结果和已搜走后的库存均保存，重复打开不会刷新。更改基础爆率/系数影响之后首次生成的容器，不刷新已经生成的库存。普通方块被破坏时会释放其剩余存货并删除旧记录，重新放置开始新的实例。配置停用不会删除库存，重新启用仍可继续访问。

F 可改键，提示随键位更新。与 GWO Pickup 1.0.1 同时安装时，准星选中地面枪械优先沿用捡枪提示和动作；搜刮时消费相同物理按键的捡枪、破译及原版副手交换输入，避免一次 F 执行两种操作。封闭保险箱按 F 接入原破译流程，打开后按 F 搜刮。

## 服务端保存与同步

新增 `tactical_inventory_loot_rules.dat` 保存容器规则，`tactical_inventory_block_loot.dat` 保存普通方块库存；原 `tactical_inventory_item_profiles.dat` 新增物品概率字段。旧稀有度和大小数据继续读取，缺少新增字段时默认不加入新掉落池。

容器规则与物品配置登录、切维度及管理员保存后同步；保存请求带配置版本，拒绝非管理员、无效 ID、非法概率、无穷/NaN 和过期编辑。F 请求由服务端重新校验生命状态、菜单状态、射线、距离、维度与实际方块，不能通过客户端指定位置隔墙开启。搜刮库存不通过配置快照公开，仍由原界面按揭示进度发送。

**客户端和服务端需一起更新。** 物品配置消息新增基础爆率与掉落池字段，网络版本已更新。

## 验证

单元测试覆盖系数乘法、上限、衰减/零值、独立物品判断、非法概率/名称/ID，以及旧物品配置默认值。独立 `run-loot-smoke` 实例加载用户的末日装饰 1.1.3 和 GWO Pickup 1.0.1，在新建世界中通过真实界面、网络消息、F 输入和渲染执行检查：

- `doomsday_decoration:acrate_2` 没有原生库存，实际注册、编辑、改名、系数、准星提示、打开原搜刮界面、库存保存恢复、重复搜刮无刷新通过。
- 原箱子内容保留，25% × 4 正确生成，双箱不重复生成；系数 0 保持空结果。
- 空池的普通方块保留第一次生成机会；权限与过期保存拒绝；伪造准星目标失败。
- 实际地面枪械和容器同时位于射线上，只有捡枪执行 F；普通搜刮不交换副手。
- 专用服务器命令、容器/物品保存与概率计算通过，无客户端类加载错误。

原生命令：

```powershell
.\gradlew.bat runClient -PraidCoreLootSmoke
.\gradlew.bat runServer -PraidCoreSmoke
.\gradlew.bat build
```

原生检查源码与测试实例不进入正式 JAR。第三方模组仅复制到独立检查目录，不修改用户的游戏、服务器存档或配置。
