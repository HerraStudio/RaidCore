# loot

搜刮容器、保险箱、破译、战利品、金条模型与素材。

游戏内通过背包顶部“搜刮管理”或管理员 `/tacticalloot` 配置容器类型、名称及爆率系数；支持所有已安装模组注册的方块，包括没有原生库存的装饰方块。物品基础爆率和掉落池开关在原物品配置页编辑，最终概率为基础爆率乘容器系数，最高 100%。准星提示 `F 搜刮` 并显示名称，注册容器的右键打开改由 F 执行。普通方块使用持久化共享库存，实际搜刮仍复用原界面。[使用和验证](../docs/LOOT_MANAGEMENT.md)。

源码位于 `src/main/java`，资源位于 `src/main/resources`，对应单元测试位于 `src/test/java`（按需添加）。

由根目录 Gradle 的 main/test 源集统一编译并打入 RaidCore 的单个 JAR；Java 包名与资源命名空间保持兼容。
启动入口及模组描述文件由项目根目录 `src/main` 统一管理。模块说明见 `../docs/MODULES.md`。
