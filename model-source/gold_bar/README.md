# Fine Gold Bar — editable loot model

Source: Fine Gold Bar by Incg5764, CC BY 4.0.
https://sketchfab.com/3d-models/fine-gold-bar-0d1ff6b3e6d045cba78889caf7f5bc6e

`gold_bar_source.glb` contains one extracted bar with original UVs and PBR maps.
`gold_bar_inspection.blend` was authored and saved through Blender Lab MCP 1.0.3 / Blender 5.2.2.
`gold_bar_animated.glb` contains real Blender actions: draw, idle and inspect, with independent wrist tracks.
`animation_authoring.json` and `provenance.json` record timing and source hashes.

Own code/animation authoring: HerraStudio. Model/texture adaptations retain CC BY 4.0.
The Blender file retains hidden default startup objects. The runtime export uses only the gold mesh and animation nodes.
